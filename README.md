# MemeAfterlife starter website

This is a beginner-friendly static prototype for the MemeAfterlife archive.

## Run it locally
1. Open `index.html` in a web browser.
2. Try searching and filtering the demo entries.
3. Submit a suggestion. It is saved only in your current browser using local storage.

## Important
- The three initial entries are fictional demo data.
- The suggestion form does not send data to a server or publish it online.
- No wallet connection or token creation is included.
- Do not add unsupported allegations about real projects.

## Publish free with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository named `memeafterlife`.
3. Upload `index.html` and this README.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select `main` and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site; use the URL shown in Settings → Pages.
